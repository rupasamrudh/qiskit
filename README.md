# My Quantum Projects

This repository contains my Qiskit-based quantum computing projects and challenge solutions. Each notebook explores a different concept in quantum circuits, measurement, and quantum correlation.

## Project Overview

### 1. Challenge 1: Predict the Output
- File: `challenge_1_solution.ipynb`
- Focus: Single-qubit circuits, measurement, and predicting simulator output.
- Topics: Quantum states, basis rotations, measurement probabilities, and output analysis.

### 2. Challenge 2
- File: `challenge_2.ipynb`
- Focus: Setting up the environment and building quantum experiments with Qiskit.
- Topics: `QuantumCircuit`, rotation gates, `AerSimulator`, and histogram visualization.

### 3. Challenge 3: Can You Change the Correlation?
- File: `challenge_3_solution.ipynb`
- Focus: Bell-state circuits and how a single gate changes correlations between qubits.
- Topics: Entanglement, measurement correlation, and logic-based reasoning about quantum behavior.

### 4. Challenge 4: Quantum Correlation Switch
- File: `challenge_4_solution.ipynb`
- Focus: Building circuits that produce either correlated or anti-correlated measurement outcomes.
- Topics: Bell states, `X` gate switching, and outcome comparison across multiple circuit variants.

## Skills and Technologies

- Python

## Repository Purpose

These projects reflect my interest in learning and exploring quantum computing through practical challenges. The notebooks combine theoretical understanding with implementation, allowing me to test predictions, interpret state behavior, and observe noisy-free simulation results from Qiskit.

## How to Use This Repository

1. Open the notebooks in Jupyter or VS Code.
2. Ensure Qiskit and supporting dependencies are installed.
3. Run the cells in order to reproduce the simulations and visualizations.
